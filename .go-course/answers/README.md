# Ответы ученика

Здесь ученик пишет **свои ответы и решения** — код, вывод команд, рассуждения.
Наставник сюда **не пишет** свои правки: ревью лежат отдельно, в `reviews/`.

## Правила

1. Один урок — один файл: `L01.md`, `L02.md`, … Ответ на урок пишется **только** в его файл.
2. Файл создаётся наставником заранее, с готовыми заголовками и чек-листом критериев приёмки.
   Ученик заполняет, не удаляя структуру.
3. Код вставляется в fenced-блоках с указанием пути файла, иначе непонятно, куда его класть.
4. Вывод команд — в fenced-блоках с подписью команды. Не пересказ своими словами: ревью
   опирается на фактический вывод.
5. Раздел «Проблемы» обязателен: что не получилось, сколько времени ушло, что гуглил, какие
   гипотезы проверял. Это часть учебного процесса, а не жалоба.
6. Файл не перезаписывается после ревью. История правок — внизу, в разделе «История»,
   чтобы было видно, как менялось решение.

## Куда что идёт

| Что | Куда |
|---|---|
| Текст урока | `lessons/lesson-NN.md` |
| Ответ ученика | `answers/LNN.md` |
| Ревью наставника | `reviews/review-NN.md` |
| Статус, вердикт, оценка | `04-progress.md` |

## Шаблон нового файла ответа

```markdown
# LNN — <название урока>

Дата работы: — · Время: — · Версия Go: —

## 1. Ответы на контрольные вопросы
## 2. Решение задания
### 2.1 Структура проекта
### 2.2 Код
### 2.3 Вывод команд
## 3. Ключевые решения и почему
## 4. Проблемы
## 5. Вопросы наставнику
## 6. История правок
```

Раздел 5 («Вопросы наставнику») — приоритетный. Если что-то непонятно, фиксируй это здесь,
а не молча делай как получится: вопрос в этом разделе часто ценнее решения.
